# Fabric Roll Stock — مخزون بكرات القماش

Production-grade fabric-roll stock management for an Egyptian fabric merchant,
deployed as a **Cloudflare full-stack application** (Workers with static
assets, or classic Pages) from this GitHub repository. Business model:

```
Warehouse (مخزن / عرض) → Fabric type (قماش) → Colour (لون) → Roll (بكرة)
```

A roll is counted. Metres come from `fabrics.meters_per_roll`. No barcode, no
serial number, no working-width model. Arabic is primary everywhere; English is
the fallback (`nm(obj, field)`).

## Security (honesty note)

Server-side RBAC (`shared/permissions.js` → `can()`) is enforced in **every**
Pages Function and in the Durable Object; the browser copy only hides buttons —
it is never trusted. Passwords are PBKDF2-SHA256 in D1, sessions expire after
12 hours, login is Turnstile-protected and rate-limited (5 failures ⇒ 60 s
lockout). The writable app requires Cloudflare and HTTPS; the offline snapshot
is read-only; Workers AI is assistive and never authoritative for stock numbers.

## Deployment

See [DEPLOY.md](DEPLOY.md). Short version: connect this repo in the Cloudflare
dashboard (deploy command `npx wrangler deploy`, wrangler 4.x) — the first
deploy needs no pre-created resources. Then create D1 + apply migrations and
enable each binding by uncommenting its template block in `wrangler.toml`
with the real resource ID. The root `wrangler.toml` serves the SPA, the API,
the WarehouseLedger Durable Object, queues and cron in one Worker.

## Tests

- `tests/logic.test.js` — independent SQL engine recomputes stock from
  `stock_events`, compares `stock_current`, the API and every number in
  `seed_manifest.json`; permissions per scope; CSV escaping; JSON round-trip;
  duplicate/invalid rules.
- `tests/api.test.js` — the real Pages Function modules on a local D1 adapter:
  login/lockout, Access JWT, Turnstile failure, server-side `can()`, transfers,
  negative-stock refusal, DO concurrency (20 simultaneous movements), Cross-View
  write-route absence, keeper-code isolation, CSV formula injection, restore.
- `tests/ui.test.js` — jsdom, mocked fetch: all 12 routes × 3 accounts × EN+AR,
  no error banner, no unresolved key, no raw `{placeholder}`, sidebar equals
  `viewsFor(user)`, accordion survives AR flip, no `innerHTML`, server print sheet.
- `tests/site.test.js` — landing page EN/AR parity, 404 bounce, doc parity with
  `seed_manifest.json`, sign-in table row-for-row vs the seed users.
- `tests/lint.js` — static rules listed above.
