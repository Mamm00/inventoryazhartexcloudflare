Security

Server-side RBAC is enforced in every Pages Function and in the Durable Object; the browser copy of can() only hides buttons. The writable app requires Cloudflare and HTTPS; the offline snapshot is read-only.

Deployment

GitHub → Cloudflare Pages Git integration. Build command: npm run build. Output: app/. The companion Worker provides Durable Objects, queues and cron.
